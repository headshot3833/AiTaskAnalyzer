# AI Task Analyzer

AI Task Analyzer — учебный ASP.NET Core Web API проект для анализа клиентских обращений с использованием локальной AI-модели.

Проект разработан в рамках кейс-задачи по теме:

**«Интеграция искусственного интеллекта в бизнес-процессы IT-компании»**

## Описание проекта

Сервис предназначен для автоматической классификации обращений клиентов IT-компании DDPlanet.

Пользователь отправляет текст обращения, после чего локальная AI-модель анализирует его и формирует результат:

- тип задачи;
- приоритет;
- ответственный отдел;
- краткое описание задачи;
- черновик технического задания.
